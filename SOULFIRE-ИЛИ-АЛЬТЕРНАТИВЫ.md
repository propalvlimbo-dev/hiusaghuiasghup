# SoulFire — это лучшие боты? Сравнение с альтернативами

Дата срезки данных: **04.10.2026**. Все цифры (звёзды, даты обновлений, поддержка версий) — на этот день.

## Короткий ответ

**SoulFire — один из лучших, но не «лучший вообще».** Он лучший в своей нише: *готовый продукт для
тестирования своего сервера реалистичными клиентами целыми флотами* (GUI + CLI + сервер + SDK +
плагины + прокси + POV-рендер). Но есть категории, где другие инструменты объективно сильнее:
тысячи соединений дешевле, точный CI-тест одного клиента, топовый pathfinding, AI-агенты.

**Нет универсального победителя — есть победитель под задачу.**

## 1. Что выбрать под задачу

| Ваша задача | Лучший выбор | Почему |
|---|---|---|
| Нагрузочный и поведенческий тест **своего** сервера «как настоящие игроки», до ~50–100 ботов, с GUI и отчётами | **SoulFire** | Настоящий клиент Minecraft (Fabric) вместо эмуляции протокола → физика, предсказание, коллизии как у игрока; всё из коробки: аккаунты, прокси, плагины, команды, POV-скриншоты, SDK |
| **Сотни и тысячи** подключений на минимуме железа | **Azalea** (Rust) или **Mineflayer** (JS), либо чистые стресс-тестеры: **rust-mc-bot**, **LambdaAttack**, **mc-bots** | Бот — легковесный процесс/задача, а не полноценный клиент. На одном ядре — десятки ботов вместо единиц |
| Скриптовые боты, чат, автоматизация, огромная экосистема готовых плагинов | **Mineflayer** | 7.5k★, MIT, поддерживает 1.8–26.1, тысячи примеров и плагинов; но физика — аппроксимация, а не клиентский код |
| Свой код на Rust с максимальной производительностью и swarm'ами в одном процессе | **Azalea** | Swarms, pathfinder на основе Baritone, точная физика (с оговорками), поддержка 26.2 |

| Исследования по RL / embodied AI | **MineRL/Malmo, MineDojo** | Академические платформы с симулятором и датасетами, не для тестов живого сервера |
| Простой чат-бот без графики, лёгкий и кроссплатформенный | **Minecraft Console Client** (MCC) | C#, 2.1k★, поддерживает 26.2, скрипты на C#, но игровая автоматизация ограничена |
| Разбор протокола / свой бот с нуля | **node-minecraft-protocol**, **MCProtocolLib**, **Botcraft** (C++) | Низкоуровневые библиотеки; Botcraft ещё и с опциональным OpenGL-рендером |
| Проверка анти-чита | Клиенты-читы (**Meteor, LiquidBounce, Wurst**) | Одиночные аккаунты, не про нагрузку |

### Про ресурсы, честно

- **SoulFire**: каждый бот — полноценный Minecraft-клиент внутри JVM. По сторонней оценке, ~50 ботов идут
  нормально, 500 — это уже серьёзное железо и тонкая настройка памяти ([minecraft.how](https://minecraft.how/blog/post/soulfire-minecraft-bot-testing)).
  В обмен вы получаете максимальную реалистичность и полный инструментарий.
- **Mineflayer/Azalea/стресс-тестеры**: бот — лёгкая задача в рантайме; один сервер тянет на порядок больше ботов.
  В обмен — поведение не идентично настоящему клиенту, и защита от ботов может вас отличать.

## 3. Где SoulFire реально лучший (и это не маркетинг)

1. **Реальная клиентская логика + почти все версии.** Через Fabric-клиент и ViaFabricPlus: 26.x, Bedrock,
   Classic, Alpha, Beta, April Fools. Ни Mineflayer, ни Azalea такого диапазона не дают.
2. **Готовность «из коробки».** Управление аккаунтами, прокси-пулом с проверкой, инстансами, правами,
   логированием чата и дисконнектов, метриками, WebDAV — у библиотек этого нет вообще.
3. **Средства наблюдения.** Headless-рендер POV (Vulkan/lavapipe, без GPU и дисплея), экспорт карт —
   можно увидеть «что видел бот», когда баг воспроизвели.
4. **Многослойная автоматизация.** Команды → визуальные скрипты → durable tasks → SDK (TS/Python) → плагины.
   Библиотеки дают только один средний слой (код).
5. **Официальный сценарий тестирования серверов.** Документация прямо описывает методику:
   baseline → ступени нагрузки → сценарии → результаты → откат.

## 4. Где SoulFire проигрывает

| Минус | Смягчение |
|---|---|
| Тяжесть: полный клиент на бота → меньше ботов на то же железо | Разделяйте слои: SoulFire для «умных» ботов, стресс-тестер/Azalea для массы |
| **AGPL-3.0** | Если встраиваете в коммерческий сервис — придётся открыть свой код; Mineflayer (MIT) и Azalea (MIT) в этом плане свободнее |
| Community меньше: ~620★ против 7.5k★ у Mineflayer | Зато это продукт, а не библиотека: вопросы реже, но меньше и кода писать |
| Сборка из исходников требует Java 25+ | Используйте готовые JAR/gui-сборки из релизов |
| Не решает за вас: анти-бот по IP, капча, онлайн-режим | Есть встроенные плагины (`captcha-solver`, `forwarding-bypass` + SoulFireBypass, `server-list-bypass`) — но настраивать надо |
| Плагины = Fabric-моды с миксинами = произвольный код | Ставить только доверенное (как с любым модом) |

## 5. Рекомендуемый стек под ваш сценарий (свой сервер, капча, прокси)

Практика показывает, что лучше не «одно универсальное», а комбинация:

1. **SoulFire** — основной инструмент: один инстанс под поведенческие тесты, GUI/CLI, POV-доказательства,
   визуальные скрипты, `captcha-solver` для проверки самой капчи, прокси-пул, `forwarding-bypass`/SoulFireBypass
   для онлайн-режима.
2. **Стресс-тестер** (`rust-mc-bot` / `mc-bots` / `LambdaAttack`) — отдельным прогоном, если нужно понять,
   на каком числе **соединений** ломается вход. Дёшево и в тысячи раз быстрее по ботам. Но помечайте в отчёте,
   что это синтетика без игровых действий.
3. **HeadlessMC + Baritone** — если нужен один-два «эталонных» клиента (например, CI-проверка плагина/мода или
   контрольный прогон маршрута настоящим клиентом с лучшим pathfinding).
4. **Mineflayer** — если захотите дешёвых ботов с богатой логикой на JS и не критична 100% верность клиенту.
5. **Azalea** — если ваш стек Rust и нужна максимальная производительность флота.

## 6. Как выбрать за 5 вопросов

1. Нужна **полная верность настоящему клиенту** (анти-чит, точная физика, свежая версия)? → SoulFire или HeadlessMC.
2. Сколько ботов нужно реально? **10–50** → SoulFire справится; **500+** → смотрите на Azalea/Mineflayer/стресс-тестеры.
3. Нужны **GUI, аккаунты, прокси, отчёты и скриншоты** без написания кода? → SoulFire.
4. Вы **разработчик**, и нужен контроль над каждым пакетом? → Mineflayer (JS) / Azalea (Rust) / MCProtocolLib (Java).
5. Вы встраиваете это в **коммерческий продукт**? → проверьте AGPL-3.0 (SoulFire) vs MIT (Mineflayer, Azalea).

---

## Итог

- **«Лучшие боты» в смысле готового продукта для теста своего сервера — да, SoulFire, вероятно, лучший
  публичный вариант**: ничего другого с таким набором (реальный клиент + ~95 версий + GUI + флот + POV + SDK)
  на рынке открытого ПО сейчас нет.
- **«Лучшая технология ботов вообще» — нет.** Для тысяч дешёвых соединений берите стресс-тестеры или
  Azalea/Mineflayer; для CI с модами — HeadlessMC; для топового pathfinding в клиенте — Baritone;
  для AI-агентов — Mindcraft.
